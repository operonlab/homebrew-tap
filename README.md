# OperonLab Homebrew Tap

Homebrew formulae for [OperonLab](https://github.com/operonlab) projects.

## Install

```bash
brew tap operonlab/tap
brew install hook-observatory
```

## Formulae

| Formula | Description |
|---------|-------------|
| [hook-observatory](https://github.com/operonlab/hook-observatory) | Safety rails for AI coding assistants |
| [session-channel](https://github.com/operonlab/session-channel) | Cross-pane, cross-CLI pub-sub bus over tmux + Redis Streams |
| [tmux-webui](https://github.com/operonlab/tmux-webui) | Web UI for tmux — your panes in any browser, with PWA + LAN/QR access |
| [hoard](https://github.com/operonlab/hoard) | Disk-space map for macOS: the CLI and MCP server (the app is on the Releases page) |
