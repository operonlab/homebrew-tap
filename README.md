# OperonLab Homebrew Tap

Homebrew formulae for [OperonLab](https://github.com/operonlab) projects.

## Install

```bash
brew tap operonlab/tap
brew install hook-observatory
```

## Formulae

| Formula | Description |
|---------|-------------|
| [hook-observatory](https://github.com/operonlab/hook-observatory) | Safety rails for AI coding assistants |
